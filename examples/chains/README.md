# Example scenario chains

These version-3, instruction-only chains demonstrate feature planning, bug
investigation, and change review. They use no catalog skills and set
`automaticPermissionOptIn` to `false`.

The JSON files are validated against `ChainSchema` by
`tests/schemas.test.js`. They are data examples, not permission to execute a
chain. They are not automatically seeded into a live API; saving them there
creates persistent records. Hosted execution remains disabled until the P5
exit gate passes.
