# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's
[security advisory reporting](https://github.com/McFuzzySquirrel/skill-loom-azure/security/advisories/new)
for this repository. Do not open a public issue containing exploit details.

## Scope

Skill Loom Azure is a non-production proof of concept. Its API and MCP
operations require Entra authentication and role checks; its public Azure
deployment profile is not a production network design. Report defects in
implemented code and deployment configuration through the private channel
above. Do not include credentials, tokens, or tenant-specific resource
identifiers in a report unless GitHub's private advisory flow requires them.
